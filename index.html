Netflix mail relay

Netflix mail relay is a small personal tool. It runs on its owner's own computer and is not offered to the public.

With the owner's permission, it watches one Gmail inbox that receives Netflix account emails. When a new email from Netflix arrives, the relay posts its subject, any sign-in or verification code, and its action links (for example, the household confirmation link) to the owner's private Telegram group, so household members can use the code before it expires.

  • It reads only the single inbox its owner authorizes, and opens it read-only. It never changes, deletes or sends email.
  • It ignores every email that is not from Netflix.
  • It does not sell, share or analyze any data.
