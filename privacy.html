Privacy policy

Last updated: 12 October 2026

phlocnguyen Mail Relay ("the app") is a personal tool run by its owner on their own computer. It is not offered to the public. This policy explains what the app does with Google user data.

Data the app accesses

With the account holder's permission, granted through Google's OAuth consent screen, the app connects to one Gmail inbox over IMAP using the https://mail.google.com/ scope. Gmail requires this scope for IMAP access. The app opens the mailbox read-only and reads new messages as they arrive. It never modifies, deletes, moves, marks or sends email.

How the data is used

The app only acts on messages from Netflix. For those messages, it checks Gmail's authentication results to make sure the message is genuine, then posts the subject, the sender address, any sign-in or verification code, and the email's action links to the owner's private Telegram group. All other messages are ignored.

Data stored

The app does not store email content. On the owner's computer it keeps only the OAuth refresh token, the number of the last processed message, and the Message-ID headers of recently processed messages (at most 500) so that no email is posted twice. Its log records message numbers and decisions only, with no email content, codes or links.

Sharing

Google user data is not sold, rented, or shared with anyone. It is not used for advertising, profiling or training any model. The only transfer is the Telegram message described above, sent to a private group chosen by the owner. Telegram's own privacy policy applies to messages stored on Telegram.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The account holder can revoke the app's access at any time at myaccount.google.com/permissions. Revoking access stops the app immediately. The owner can delete the locally stored token and state at any time.

Contact

Questions about this policy can be raised on the app's GitHub issues page.
